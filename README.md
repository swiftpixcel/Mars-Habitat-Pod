# Mars-Habitat-Survival pod and mini rover
This is a project in which it discribes the living of humans if they went to mars and how will they able to mintain humidity air and temprature!
It also includes a mini rover which will be for the irrigation system and it will be automatically wattering the plants and following its track using ir sensors and moisture sensor! this will help in auto irrigation yustem
The Mars habitat pod will include a carbon filter which filter dusts and purifies and mintaining air quality! the pod also features with temprature sensor which measures temprature a oled which displays all the required equipments and many more!
# Key features
It has a custom pcb which is built for this project and is designed in Easy EDA
it also features a small humidity mist module which controls humidity when its low
A base is also provided in the 3D view which is 3D printable! and it is ready to go and can be easily 3D printable!
